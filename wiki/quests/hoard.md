# Treasure Hoards

Treasure hoards are glowing piles of treasure found in dungeons. They are not quests in the traditional sense but offer significant loot for adventurers who find them.

## How It Works

1. Find a **treasure hoard pile** in a dungeon (glowing item on the ground).
2. Double-click the pile to pull an item from it.
3. You can loot up to **5 items** before the pile is exhausted.
4. The pile despawns after 10 minutes or when emptied.

## Possible Loot

Each pull gives a random reward:

| Chance | Reward |
|--------|--------|
| 1/17 | Rare artifact |
| 2/17 | Semi-rare artifact |
| 1/17 | Relic item |
| 1/17 | Rare item |
| 1/17 | Rare book |
| 1/17 | Scroll |
| 1/17 | Gold (1,000-2,000 + Luck bonus) |
| 4/17 | Enchanted magical item (+500 enchant power) |
| 1/17 | Enchanted instrument |
| 1/17 | Gem |
| 1/17 | Potion |
| 1/17 | Magical wand |
| 1/17 | **Treasure chest** (ends looting, high-level chest with extra gold and possible artifact) |

## Special Locations

- In the **Ancient Crash Site / Sky Ship**: piles give Xormite instead of gold.
- In the **Mines of Morinia**: piles give Crystals instead of gold.
- In the **Underworld**: piles give Jewels instead of gold.

## Tips

- Higher **Luck** improves item quality and may grant extra looting attempts.
- The treasure chest (if pulled) ends the pile immediately but contains very high-value loot.
- Hoard pile names reference the dungeon they appear in.
