# Museum Quests (Antiques)

Museum quests involve finding antique items in dungeons and selling them to art collectors for gold.

## How It Works

1. Find an **antique** item in a dungeon (heavy, 10-stone decorative items).
2. Double-click the antique while it's in your backpack to see its sale value.
3. Sell it to an **art collector** NPC for gold.

## Antique Value

The base value is set when the antique is generated. Bonuses stack:

| Bonus Source | Effect |
|--------------|--------|
| Base Value | Set per antique |
| Mercantile Skill | Up to +25% at GM Mercantile |
| Begging Skill | Up to +25% at GM Begging (must be in begging pose) |
| Merchant Guild | +25% if you are a Merchant Guild member |

## Antique Features

- Antiques are named "antique" with a description property.
- They record the name of the player who discovered them.
- Some antiques are interactive (lamps, candles, fireplaces can be toggled on/off when placed in the world).

## Tips

- High Mercantile skill + Merchant Guild membership + Begging can nearly double the sale price.
- Antiques are heavy (10 stones each) -- plan your inventory.
- Begging while selling costs karma.
