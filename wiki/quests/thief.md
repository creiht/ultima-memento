# Thief Quests (Pedestal Stealing)

Thief quests involve stealing valuable containers from trapped pedestals found in dungeons. These require Snooping and Stealing skills.

## How to Start

Find a **Steal Base** -- a box, chest, or bag sitting on a pedestal in a dungeon. These are visually distinct with ornate carvings in various languages.

## How It Works

1. Approach the pedestal and use the container on it.
2. You must pass a **Snooping** check to examine it.
3. Then pass a **Stealing** check to take the container.
4. Failing Snooping may trigger a **trap** (unless you also pass Remove Trap).

## Traps

If you fail the Snooping check and fail Remove Trap, one of these traps triggers:

| Trap Type | Effect |
|-----------|--------|
| Poison Gas | Poison (Lesser to Deadly) |
| Explosion | 10-80 fire damage |
| Blade | 10-80 physical damage |
| Flame | 10-80 fire damage |
| Lightning | 10-80 energy damage |

After **6 failed attempts**, the container and its contents vanish permanently.

## Container Types

| Type | Material |
|------|----------|
| Metal Box | Random metal type (iron through valorite) |
| Wooden Box | Random wood type |
| Leather Bag/Sack/Pouch | Random leather type |

Each container has unique carvings in a random language (elven, draconic, orcish, etc.).

## Loot

Successfully stolen containers contain a mix of:

| Loot Type | Chance |
|-----------|--------|
| Rare Artifact | Rare |
| Semi-rare Artifact | Uncommon |
| Enchanted Items | Common |
| Gold (4,000-16,000) | Common |
| Relics | Luck-based |
| Rare Items | Luck-based |
| Books, Scrolls | Luck-based |
| Gems, Potions | Luck-based |
| Magic Wands | Luck-based |

## Thief Notes

If you carry a **Thief Note** (a quest from the thieves' guild), opening a Steal Base in the correct location completes the note's objective.

## Puzzle Boxes

Players with the **Puzzle Box** temptation can solve a puzzle mini-game instead of skill checks for additional rewards.

## Tips

- High Snooping, Stealing, and Remove Trap skills are essential.
- Luck affects the quality and quantity of loot in the stolen container.
- There is a **daily throttle** on pedestal stealing to prevent excessive farming.
- Steal Bases also serve as interaction points for Museum Book and Major Quest objectives.
