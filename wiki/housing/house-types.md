# Classic House Types

Every classic (pre-built) house available through the Construction Contract or individual deeds is listed below. Columns sourced from `HousePlacementEntry` data in `HousePlacementTool.cs:649–719`.

**Column key:**
- **Storage** — maximum item count for storage accounting (AOS mode).
- **Lockdowns** — maximum lockdown slots.
- **Vendors** — maximum vendor slots from the placement entry.
- **Cost** — gold withdrawn from bank on placement.

## Notes

- Storage and lockdown values shown are the AOS (non-ML) values from the placement entry. The ML bonus storage scalar (×1.2) applies only in ML mode; this server uses AOS mode without the ML scalar.
- The `Vendors` column is the entry-level cap; the actual in-game limit follows vendor-slot accounting per `BaseHouse.cs`.
- For tent-specific details (Blue Tent, Green Tent, Large Tent), see [Tents](tents.md).
- For custom-designed sizes, see [Custom Foundations](custom-foundations.md).
