# Druidism

Druidism is nature-based magic that uses herbal mixtures and druidic knowledge. It uses [Druidism](../skills/druidism.md) for casting and [Veterinary](../skills/veterinary.md) for damage calculations. Spells are organized into circles and cast using a Druid Pouch.

## Requirements

- **Skill:** [Druidism](../skills/druidism.md)
- **Damage Skill:** [Veterinary](../skills/veterinary.md)
- **Equipment:** Druid Pouch (contains herbal mixtures)

## How to Learn

Acquire a Druid Pouch and herbal potions/mixtures. Brew herbal recipes using the Book of Druid Brewing to create the mixtures needed for druidic spells.

## Spell List

| Spell | Effect |
|-------|--------|
| Shield of Earth | Creates an earthen shield protecting the caster |
| Woodland Protection | Grants natural protection from the forest |
| Protective Fairy | Summons a fairy to protect and aid the caster |
| Herbal Healing | Uses herbal mixtures to heal wounds |
| Grasping Roots | Roots emerge to entangle and immobilize a target |
| Blend with Forest | Camouflages the caster, blending into natural environment |
| Swarm of Insects | Summons a swarm of biting insects to attack enemies |
| Volcanic Eruption | Calls forth a volcanic eruption dealing fire damage |
| Treefellow | Summons a treant ally to fight alongside the caster |
| Stone Circle | Creates a protective circle of standing stones |
| Druidic Rune | Marks a rune to the caster's location |
| Lure Stone | Creates a stone that lures creatures |
| Nature's Passage | Teleports through nature to a marked rune location |
| Mushroom Gateway | Opens a portal through a mushroom ring to a marked location |
| Restorative Soil | Heals damage using the restorative power of the earth |
| Firefly | Summons fireflies to illuminate the area |

## Notes

- Druid spells are prepared using herbal mixtures brewed in a Druid Pouch.
- The Book of Druid Brewing contains recipes for creating these mixtures.
- Herbal Potions can also be brewed independently using the herbalism system.
