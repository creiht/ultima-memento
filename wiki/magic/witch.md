# Witch (Witch Brews)

Witch magic uses necromantic brews and undead potions. It relies on [Necromancy](../skills/necromancy.md) for casting and [Forensics](../skills/forensics.md) for damage. This school focuses on dark liquid concoctions that produce spell effects when consumed or thrown.

## Requirements

- **Skill:** [Necromancy](../skills/necromancy.md)
- **Damage Skill:** [Forensics](../skills/forensics.md)
- **Karma:** Casting reduces Karma (must have Karma above -2,459)
- **Equipment:** Witch Pouch (contains brews)

## How to Learn

Acquire a Witch Pouch and the Book of Witch Brewing. Brew elixirs and use them to trigger spell effects.

## Spell List

| Brew | Effect |
|------|--------|
| Spectre Shadow | Incorporeal movement through objects |
| Mana Leech | Drains mana from a target |
| Cure Poison | Cures poison using necromantic means |
| Hell's Brand | Brands target with infernal fire damage |
| Graveyard Gateway | Opens a gateway through a graveyard to a marked location |
| Retched Air | Creates a cloud of noxious gas |
| Undead Eyes | Grants dark vision and enhanced perception |
| Wall of Spikes | Creates a wall of damaging spikes |
| Vampire Gift | Grants vampiric abilities temporarily |
| Blood Pact | Pact that shares damage and life force |
| Necro Poison | Applies deadly necromantic poison |
| Hell's Gate | Opens a gateway to a hellish location |
| Ghostly Images | Creates ghostly duplicates to confuse enemies |
| Ghost Phase | Phase through physical barriers |
| Necro Unlock | Magically opens locked containers |
| Phantasm | Creates a powerful phantasmal illusion |

## Notes

- Witch brews are the dark counterpart to [Druidism](druidism.md) herbal potions.
- Casting witch brews reduces Karma.
- Brews are prepared using the Book of Witch Brewing and stored in a Witch Pouch.
