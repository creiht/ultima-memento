# Shinobi

Shinobi abilities are advanced ninja techniques that go beyond standard [Ninjitsu](ninjitsu.md). They are learned from Shinobi Scrolls found throughout the world and use [Ninjitsu](../skills/ninjitsu.md) skill with Tithing Points as a resource.

## Requirements

- **Skill:** [Ninjitsu](../skills/ninjitsu.md)
- **Resource:** Tithing Points
- **Learning:** Shinobi Scrolls (each scroll teaches one ability)

## How to Learn

Find Shinobi Scrolls in dungeons and from enemies. Each scroll teaches a specific ability permanently.

## Spell List

| Ability | Command | Min Skill | Tithing | Effect |
|---------|---------|-----------|---------|--------|
| Cheetah Paws | `[CheetahPaws` | - | - | Run at increased speed (like a mount); restricted in some areas |
| Deception | `[Deception` | - | - | Disguise yourself to deceive enemies |
| Eagle Eye | `[EagleEye` | - | - | Enhanced perception to detect hidden things |
| Espionage | `[Espionage` | - | - | Spy on targets from a distance |
| Ferret Flee | `[FerretFlee` | - | - | Quick escape ability to flee from danger |
| Monkey Leap | `[MonkeyLeap` | - | - | Leap across distances to reach new locations |
| Mystic Shuriken | `[MysticShuriken` | - | - | Throw a magical shuriken at a target |
| Tiger Strength | `[TigerStrength` | - | - | Temporarily increases physical power |

## Notes

- Abilities must be learned from scrolls before they can be used.
- Cheetah Paws is disabled in certain restricted areas (dungeons, caves, indoors).
- Cast recovery is fast (2 base).
- Shinobi abilities complement standard [Ninjitsu](ninjitsu.md) abilities.
