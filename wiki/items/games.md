# Games

Ultima Memento features a variety of in-game games for entertainment and social interaction.

## Board Games

| Game | Description | How to Obtain |
|------|-------------|---------------|
| Chess Board | Playable chess game with movable pieces | Crafting, purchase |
| Checker Board | Playable checkers game | Crafting, purchase |
| Backgammon Board | Playable backgammon | Crafting, purchase |
| Mahjong Game | Full Mahjong game with tiles and scoring | Crafting, purchase |

## Casino Tokens

Casino tokens are used as currency in casino game areas. They can be exchanged for gold.

## Liar's Dice Details

Liar's Dice is a full multiplayer bluffing game with dedicated UI:
- Players roll dice in secret
- Take turns making increasingly bold claims about all dice on the table
- Call "bluff" to challenge the previous player's claim
- Last player standing wins
