# Books

Books in Ultima Memento include readable lore books, trade skill manuals, power scrolls, and bulletin boards. Many provide valuable information about the game world and its systems.

## Readable Books

| Book | Description | How to Obtain |
|------|-------------|---------------|
| Beginner Book | Introductory guide for new players | Starting area |
| Lore Book | Contains world lore and stories | Libraries, loot |
| Writing Book | Player-writable book (BaseBook) | Purchase, crafting |
| Dynamic Book | Books with procedurally generated content | Loot |
| Bard's Tale Note | Story note related to the Bard's Tale questline | Bard's Tale dungeon |
| Doom Flayer Note | Note found in the Doom dungeon | Doom dungeon |
| Swords and Shackles | Lore book about combat and imprisonment | Libraries, loot |

## Trade Skill Manuals

These books teach knowledge about specific crafting materials when read:

| Book | Skill | Content |
|------|-------|---------|
| Learn Metal | Blacksmithing | Information about metal types and their properties |
| Learn Leather | Tailoring | Information about leather types |
| Learn Wood | Carpentry | Information about wood types |
| Learn Granite | Mining | Information about granite types |
| Learn Scales | Various | Information about scale types |
| Learn Tailor | Tailoring | Additional tailoring material info |
| Learn Misc | Various | Miscellaneous crafting materials |
| Learn Reagents | Alchemy/Magery | Reagent identification and properties |
| Learn Stealing | Stealing | Guide to the stealing skill |

## Power Scrolls

Power Scrolls increase the maximum skill cap for a specific skill beyond 100.

| Item | Effect | How to Obtain |
|------|--------|---------------|
| Power Scroll | Raises a skill cap to 105, 110, 115, or 120 | Champion spawns, special events |

Power Scrolls can also be purchased from special vendors.

## Title Change Deed

Allows you to change your character's displayed title.

## Bulletin Boards

Bulletin boards are found in towns and provide community information:

| Board | Purpose |
|-------|---------|
| Admin Board | Server announcements |
| Guild Board | Guild-related postings |
| Patch Board | Patch notes and updates |
| Rules Board | Server rules |
| Status Board | Server status information |
| Stealing Board | Theft-related notices |
| Assassin Note | Assassination contracts |
| Guard Note | Guard postings |
| Wanted: Mangar | Special wanted poster |
