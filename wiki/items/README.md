# Items Overview

This section documents all item categories available in Ultima Memento. Items are found throughout the world via crafting, looting, questing, and purchasing from merchants. For details on how items drop from creatures and chests, see [Loot Tables](../systems/loot-tables/README.md).

## Item Identification

Many items found in the world are unidentified. Use the **Mercantile**, **Arms Lore**, or **Tasting** skills to identify items and reveal their true value and properties. Some items can be identified by double-clicking them in your backpack if you have the Double-Click ID preference enabled.
