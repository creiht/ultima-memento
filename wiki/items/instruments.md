# Musical Instruments

Musical instruments are used by bards for the **Musicianship**, **Provocation**, **Peacemaking**, and **Discordance** skills. All instruments are craftable and can receive magical properties and slayer enchantments.

## Instrument Types

| Instrument | Weight | Default Resource | Notes |
|------------|--------|-----------------|-------|
| Flute (Bamboo Flute) | 2.0 | Wood | — |
| Drum | 4.0 | Wood | — |
| Fiddle | 5.0 | Wood | — |
| Harp | 35.0 | Wood | Large floor instrument |
| Lap Harp | 10.0 | Wood | Smaller, portable harp |
| Lute | 5.0 | Wood | — |
| Magic Horn | 5.0 | Metal (Iron) | Metal-based instrument |
| Pipes | 5.0 | Wood | — |

| Tambourine (Tassel) | 1.0 | Wood | Variant with tassel |
| Trumpet | 5.0 | Metal (Iron) | Metal-based instrument |

## Base Properties

All instruments share these properties from `BaseInstrument`:

| Property | Details |
|----------|---------|
| Uses | 150-200 base uses (scales with quality) |
| Quality | Low, Regular, Exceptional |
| Durability | Has hit points; breaks when depleted |
| Slayer | Can have up to 2 slayer properties |
| Skill Bonuses | Up to 5 skill bonuses possible |
| Resistances | Physical/Fire/Cold/Poison/Energy (base 0, modified by resource) |
| Charge Replenish | Recharges uses over time (every 5 minutes) |

## Resource Bonuses

- **Wood instruments** (default: Regular Wood) benefit from wood resource types (Ash, Cherry, Ebony, etc.)
- **Metal instruments** (Magic Horn, Trumpet) benefit from metal resource types (Iron, Dull Copper, etc.)
- Higher-tier resources provide resistance bonuses and may improve performance

## Crafting

Instruments are crafted via **Carpentry** (wood instruments) or **Tinkering** (metal instruments). Exceptional quality instruments have increased uses and may receive additional properties. The resource material affects the hue and bonuses.

## How to Obtain

- Craft via Carpentry or Tinkering
- Purchase from bard shops and music vendors
- Loot from monsters and treasure chests
