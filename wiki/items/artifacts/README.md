# Artifacts

Artifacts are unique named items with **fixed, permanent stats** that cannot be modified or regenerated by the random loot system. Each artifact has a canonical name, designated enchantments, and an artifact level.

Unlike [relics](../relics.md) (primarily decorative/housing items), equippable artifacts are intended for combat and character builds.

## Artifact Levels

| Level | In-game Label | Notes |
|---|---|---|
| `Artifact` | Minor Artifact | Utility/flavor items; mostly not in the Sage quest chain |
| `StandardArtefact` | Artefact | Most equippable artifacts |
| `LegendaryArtefact` | Legendary Artefact | Reserved for a handful of exceptional items |
| `DecorativeArtefact` | Decorative Artefact | Display/housing use (e.g. Ghost Ship Anchor) |

## Obtaining Artifacts

### Sage Artifact Quest

The primary route for the 308 artifacts in the quest list:

1. Visit a **Sage** NPC and buy an *Encyclopedia of Artifacts* for 10,000&nbsp;gold.
2. Browse the encyclopedia and select a target artifact.
3. Receive a **Search Page** with a dungeon coordinate pointing to a hidden `SearchBase` stone.
4. Travel to the indicated facet and location, find the stone, and claim the artifact.

Available facets: Sosaria, Lodoria, Serpent Isle, Isles of the Dread, Savaged Empire, Umber Veil, Kuldar, Underworld, Ambrosia.

The Sage uses **70% legend accuracy** — occasionally the hint may be slightly off.

## Common Mechanics

- All artifacts show their **artifact level** in the tooltip.
- Artifacts are **identity-locked**: equipping calls `Arty.setArtifact()` which resets name and appearance to canonical values.
- The server setting `S_ChangeArtyLook` (`Settings.cs`) controls whether the artifact's appearance can be changed; locked by default.
- Some artifacts display a **tooltip hint** (e.g. `(Casts Lightning)`) indicating a special double-click action.
