# Traps

The Traps category (28 files) covers trap items, trap mechanisms, and trap-related systems. Traps are encountered in dungeons, on treasure chests, and can be set by players.

## Trap Types Found on Containers

Dungeon chests and treasure chests may be trapped with:

| Trap | Effect |
|------|--------|
| Poison Trap | Poisons the opener |
| Explosion Trap | Deals fire damage |
| Dart Trap | Shoots a projectile |
| Magic Trap | Casts a harmful spell |

## Player-Set Traps

Players with the **Remove Trap** and **Tinkering** skills can create and place traps:

| Trap | Description |
|------|-------------|
| Landmine | Explodes when stepped on (see [Technology](technology.md)). Power based on Remove Trap skill. Max 3 per area. |
| Poison Trap Kit | Creates a poison trap on a container |
| Explosion Trap Kit | Creates an explosion trap on a container |

## Removing Traps

- **Remove Trap** skill: Disarm traps on containers and in the world
- **Plasma Torch**: Technology item that melts through traps and locks (see [Technology](technology.md))
- **Detect Hidden**: Helps locate hidden traps
- **Magic Trap/Untrap**: Spells for handling magical traps

## Trap Mechanics

1. Opening a trapped container triggers the trap
2. Trap damage and effect scale with the trap's level
3. Higher-level dungeon chests have more dangerous traps
4. Successfully removing a trap provides Remove Trap skill gain
5. Failed trap removal may trigger the trap

## Tips

- Always check containers with Detect Hidden before opening in dungeons
- Carry cure potions and heal potions when exploring trapped areas
- Tinkers can craft trap kits for home defense
- The Remove Trap skill is valuable for treasure hunters
