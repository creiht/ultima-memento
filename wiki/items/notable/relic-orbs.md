# Relic: Crystal Balls

Crystal balls are mystical relic items featuring randomly generated names from a vast list of magical-sounding words.

## Properties

| Property | Value |
|----------|-------|
| Weight | 15-40 stones |
| Gold Value | 80-500 gold |
| ID Skill | Mercantile |
| Light | Emits glow |

## Naming Convention

Each crystal ball has a unique name following the pattern: **[Wizard Name]'s [Adjective] Crystal Ball**

- Wizard names are drawn from a pool of hundreds of fantasy-sounding names (Clyz, Achug, Theram, Quale, etc.)
- Adjectives include: Exotic, Mysterious, Enchanted, Marvelous, Magical, Divine, Legendary, Sacred, Forgotten, and many more

## Special Effect

When double-clicked after identification, the crystal ball shows a random vision:
- "You see a prince in the orb..."
- "You see a dragon in the orb..."
- "You see a shadow in the orb..."
- Over 50 different possible visions including kings, queens, demons, angels, maidens, and more

This is purely for flavor and entertainment.

## Appearance Variants

Crystal balls come in several different shapes and sizes, using different item graphics.

## How to Obtain

Found as dungeon loot, monster drops in magical areas, and in treasure chests.
