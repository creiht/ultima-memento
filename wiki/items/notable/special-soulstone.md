# Soul Stone

The Soul Stone is one of the most valuable special items in the game, allowing players to store and retrieve skill points.

## Properties

| Property | Value |
|----------|-------|
| Type | Special / Veteran reward |
| Function | Stores skill points for later retrieval |

## How It Works

1. Use the Soul Stone and select a skill
2. The skill points are removed from your character and stored in the stone
3. Later, use the stone again to retrieve those skill points
4. This effectively allows you to "swap" skill builds without permanently losing training

## Uses

- Switch between combat and crafting builds
- Store a fully trained skill while experimenting with a new one
- Manage your limited skill point cap across multiple disciplines

## How to Obtain

Soul Stones are obtained through veteran rewards and rare special loot.
