# Soul Stone

The Soul Stone is one of the most valuable special items in the game, allowing players to extract a skill from their character and store it — or transfer it to another character on the same account.

## Properties

| Property | Value |
|----------|-------|
| Type | Special / Veteran reward |
| Light | Circle300 (glows) |
| Account Binding | Binds to the account of the first character who uses it |
| Stores | 1 skill at a time |

## Variants

| Variant | Notes |
|---------|-------|
| SoulStone (standard) | Unlimited uses; binds on first use |
| SoulstoneFragment | **5 uses** by default (configurable), then destroyed |
| BlueSoulstone | Cosmetic variant; same behavior as standard |
| RedSoulstone | Cosmetic variant; may be a veteran reward item |

## How It Works

### Storing a Skill

1. Double-click the Soul Stone (must be within 2 tiles, accessible, in a safe logout location).
2. A GUMP lists all skills with a base value > 0. Select the skill you want to extract.
3. Confirm the transfer. The skill must be **locked to decrease** (skill lock pointing down) in your skills panel.
4. All skill points in that skill are removed from your character and stored in the stone.
5. The stone changes appearance to indicate it is occupied.

### Retrieving a Skill

1. Double-click the stone when it contains a skill.
2. If the Avatar mode warning appears (Avatar activated + stone was unbound), read it — the Avatar system may restrict retrieval.
3. The skill stored must be ≤ your individual skill cap for that skill. Raise the cap with power scrolls first if needed.
4. Skills locked to increase and with enough free skill points will allow absorption. Skills in "other characters" on the account can also absorb from it.
5. Confirm retrieval — the stored value **replaces** (does not add to) your current value in that skill. If the stored value is 100 and your current is 30, you will have 100 after (and will need to free 70 skill points from other skills).
6. Alternatively, choose to **permanently delete** the stored skill points (no gains to any character).

## Restrictions

You cannot use a Soul Stone if you are:
- In combat (within 2 minutes of last combat action)
- A criminal (within 2 minutes)
- In a region with a logout delay (unsafe location)
- Dead
- Casting a spell
- Poisoned
- Paralyzed
- Under a Scroll of Alacrity effect

## Account Binding

- An unbound stone shows "Binds to account when used" in its tooltip.
- Once used, it binds permanently to that account. Any character on the same account can use it to store or retrieve skills.
- A bound stone that a non-account character tries to use displays an error.

## How to Obtain

Soul Stones are obtained through veteran rewards (standard and colored varieties) and rare special loot.
