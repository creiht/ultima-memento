# Alien Egg

The Alien Egg is a complex technology quest item that requires multiple components to activate.

## Properties

| Property | Value |
|----------|-------|
| Weight | 3.0 stones |
| Type | Technology quest item |
| Hue | 0xBAB (alien green) |

## Required Components

To activate the Alien Egg, you must collect:

1. **Rod** — A special component
2. **Yellow Crystal** — Found in alien areas
3. **Red Crystal** — Found in alien areas
4. **Potion** — A specific alchemic mixture
5. **Xormite** — 10,000 units of xormite ore

## Quest Steps

1. Find the Alien Egg in alien/sci-fi themed areas
2. Travel to a specific location in the Savaged Empire (coordinates 1197-1218, 3655-3676) to initialize the egg
3. Collect all required components
4. The egg provides rumor hints about where to find the missing components
5. An animal trainer location is randomly assigned for part of the quest

## How to Obtain

Found in alien-themed areas of the game world. The egg itself is the start of a multi-step quest chain.
