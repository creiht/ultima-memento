# Relic: Ancient Coins

Ancient coins are relic items depicting symbols of lost civilizations. Each coin set features a unique symbol and origin story.

## Properties

| Property | Value |
|----------|-------|
| Weight | 5.0 stones |
| Gold Value | 80-500 gold |
| ID Skill | Mercantile |

## Coin Symbols

Coins may depict: tower, griffin, crown, sword, axe, lion, bear, bat, boar, buffalo, chimera, snake, demon, and many more (34+ symbol types).

## Coin Origins

Each set is described as being "from": a long dead civilization, an ancient race, a secret order, a far off land, a lost city, a mysterious land, the dark times, an old race, a missing land, or an unknown era.

## How to Obtain

Found in dungeon loot, treasure chests, and monster drops throughout the world.
