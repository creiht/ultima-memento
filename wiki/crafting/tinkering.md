# Tinkering

Tinkering creates tools, parts, jewelry, utensils, wizard weapons, and miscellaneous items.

- **Skill**: Tinkering
- **Tool**: Tinker Tools
- **Primary Resource**: Metal Ingots, Wood (Boards)
- **Supports**: Repair, Breakdown, Enhancement

## Materials

Tinkering uses **Metal Ingots** (Iron through Dwarven, plus Sci-Fi metals) and **Wood Boards** (Regular through Elven, plus Sci-Fi woods). Full tier tables, hues, stat bonuses, and harvest sources are on the [Mining](mining.md) and [Lumberjacking](lumberjacking.md) pages.

## Metal Tiers

Iron, Dull Copper, Shadow Iron, Copper, Bronze, Gold, Agapite, Verite, Valorite, Nepturite, Obsidian, Steel, Brass, Mithril, Xormite, Dwarven

## Jewelry

Tinkering creates jewelry using ingots and gemstones. Each gem type produces bracelets, circlets, earrings, necklaces, and rings:

| Gem | Skill Modifier | Gems Available |
|---|---|---|
| Amber | +5 | Amber |
| Citrine | +10 | Citrine |
| Ruby | +15 | Ruby |
| Tourmaline | +20 | Tourmaline |
| Amethyst | +25 | Amethyst |
| Emerald | +30 | Emerald |
| Sapphire | +35 | Sapphire |
| Star Sapphire | +40 | Star Sapphire |
| Diamond | +45 | Diamond |
| Pearl | +50 | Oyster |

Base skill ranges from 40.0 + gem modifier. Each piece requires 2-3 ingots and 1 gemstone.
