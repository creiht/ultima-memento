# Commands

In Ultima Memento, commands are entered in-game by typing `[commandname` (with the opening bracket `[` as the command prefix). Some commands accept arguments after the command name.

## How to Use Commands

1. Open the chat/command input in your UO client
2. Type `[` followed by the command name (e.g., `[bandself`)
3. Some commands accept parameters after the name (e.g., `[emote bow`)
4. Some commands open a graphical window (gump) for interaction
5. Some commands toggle a setting on/off each time they are used

## Command Categories

### Player Commands

Commands available to all players. These handle combat, inventory, UI bars, music, emotes, and character settings.

See: [Player Commands](player-commands.md)

### Admin Commands

Commands restricted to staff members (Counselor, GameMaster, Administrator). These handle world building, player management, debugging, and server administration.

See: [Admin Commands](admin-commands.md)

## Quick Reference — Most Used Player Commands

| Command | What It Does |
|---------|-------------|
| `[bandself` | Apply bandages to yourself |
| `[combatbar` | Open the combat status bar |
| `[corpse` | Get directions to your corpse |
| `[loot` | Configure automatic looting |
| `[quickbar` | Open the quick action bar |
| `[wealth` | Open the wealth tracking bar |
| `[emote <action>` | Perform an emote with sound/animation |
| `[music` | Open the music playlist |
| `[afk` | Toggle AFK mode |
