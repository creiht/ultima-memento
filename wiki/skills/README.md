## Disabled Skills

These skills appear in the skills gump but are **not active** in Ultima Memento. They cannot be trained, targeted by powerscrolls, or selected in character creation.

| Skill | Notes |
|---|---|
| [Imbuing](imbuing.md) | OSI Stygian Abyss enchanting skill — not implemented. See Inscription and Tinkering instead. |
| [Throwing](throwing.md) | OSI Gargoyle throwing-weapon skill — not implemented. Train Marksmanship instead. |
