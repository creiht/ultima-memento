# Skills

A complete reference for all skills in Ultima Memento. Click any skill name for details on what it does, how to train it, and how it synergizes with other skills.

## Combat Skills

| Skill | What It Does |
|---|---|
| [Tactics](tactics.md) | Amplifies attack damage and gates weapon special ability tiers |
| [Healing](healing.md) | Mend wounds, cure poison, and stop bleeding |
| [Parrying](parrying.md) | Raise your shield to absorb melee and magical damage |
| [Anatomy](anatomy.md) | Evaluate targets to learn their physical stats and weaknesses |

## Weapon Skills

| Skill | What It Does |
|---|---|
| [Swordsmanship](swordsmanship.md) | Hit skill for bladed melee weapons |
| [Bludgeoning](bludgeoning.md) | Hit skill for clubs, maces, and blunt weapons |
| [Fencing](fencing.md) | Hit skill for spears, kryss, sai, and piercing weapons |
| [Fist Fighting](fist-fighting.md) | Unarmed combat; prerequisite for Mystic (Monk) magic |
| [Marksmanship](marksmanship.md) | Hit skill for all ranged weapons |

## Magic Skills

| Skill | What It Does |
|---|---|
| [Magery](magery.md) | Casting skill for the traditional 8-circle arcane magic |
| [Necromancy](necromancy.md) | Casting skill for dark death magic |
| [Knightship](knightship.md) | Casting skill for both Paladin (Chivalry) and Death Knight magic |
| [Bushido](bushido.md) | Samurai combat techniques — stances, strikes, and evasive parries |
| [Ninjitsu](ninjitsu.md) | Shadow-art skills including Animal Form and Death Strike |
| [Elementalism](elementalism.md) | Reagent-free magic across 8 Spheres of elements |
| [Meditation](meditation.md) | Enter a trance to regenerate mana faster |
| [Focus](focus.md) | Passively boost stamina and mana regeneration |
| [Inscription](inscription.md) | Copy spell contents between books; scribing for Research |
| [Psychology](psychology.md) | Evaluate intelligence; enhances nearly every magic system |
| [Spiritualism](spiritualism.md) | Channel energy to heal yourself and others |
| [Magic Resistance](magic-resistance.md) | Passively resist hostile spell effects |
