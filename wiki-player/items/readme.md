# Items Overview

Ultima Memento features over 25 item categories. Items are found through crafting, looting, questing, and purchasing from merchants.

## Item Categories

| Category | Description |
|---|---|
| Armor | Protective equipment for all body slots |
| Weapons | Swords, axes, maces, bows, spears, and more |
| Clothing | Non-armor wearables — robes, cloaks, hats, shoes |
| Potions | Health, mana, stamina, and special effect drinks |
| Books | Spellbooks, power scrolls, trade manuals, lore |
| Gems | Precious stones and crystals (crafting and enchanting) |
| Containers | Bags, chests, treasure chests, backpacks |
| Deeds | Consumable contracts — house deeds, addon deeds, etc. |
| Magical | Enchanted gear, scrolls, reagents, wands |
| Food | Edible items, beverages, cooking ingredients |
| Trinkets | Jewelry, talismans, light sources |
| Relics | Collectible dungeon relics worth gold |
| Artifacts | Unique named items with fixed stats |
| Containers | Bags, chests, and storage |
| Tools | Crafting tools and harvest instruments |
| Traps | Trap items and trap-related mechanics |
| Games | Board games, card games, dice |
| Houses | Player housing components |
| Boats | Ships and seafaring equipment |
| Trinkets | Jewelry, talismans, light sources |
| Technology | Sci-fi / alien tech items |
| Special | Rare decorative and reward items |
| Misc | Tools, keys, lights, dyes |

## Item Identification

Many items found in the world are unidentified. Use the **Mercantile**, **Arms Lore**, or **Tasting** skills to identify items and reveal their true value and properties. Some items can be identified by double-clicking them with the Double-Click ID preference enabled.
