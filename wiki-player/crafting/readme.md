# Crafting Overview

Ultima Memento features over 20 crafting professions, multiple harvesting skills, and trade support systems. Each profession requires a specific skill, tools, and resources.

## Material Tiers

Many professions support multiple material tiers that unlock at higher skill levels. Using higher-tier materials produces items with better stats. Common tiers include:

- **Metals:** Iron → Dwarven → Titanium → Mithril → Obsidian → more
- **Wood:** Regular → Elven → Ebony → Ghostwood → more
- **Leather:** Regular → Dragon → Demon → more
- **Fabric:** Regular → Fiendish (with intermediate tiers)

## Repair & Enhancement

Most crafted items can be:
- **Repaired** — fix durability using the appropriate tool
- **Salvaged** — break down into raw materials
- **Enhanced** — improve with special materials at higher skill levels
