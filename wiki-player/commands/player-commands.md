# Player Commands

All commands are entered in-game by typing `[commandname` (the `[` is the command prefix). Some commands accept arguments after the command name.

## Most Used Commands

| Command | What It Does |
|---|---|
| `[bandself` | Apply bandages to yourself automatically |
| `[bandother` | Apply a bandage to a targeted person |
| `[combatbar` | Open the combat status bar |
| `[quickbar` | Open the quick action bar |
| `[wealth` | Open the wealth tracking bar |
| `[loot` | Configure automatic looting from corpses |
| `[corpse` | Get directions to your nearest corpse |
| `[magicgate` | Get directions to the nearest moongate |
| `[afk` | Toggle AFK mode |
| `[autoattack` | Toggle auto-counter-attack when attacked |
| `[emote <action>` | Perform an emote (bow, clap, laugh, etc.) |
| `[music` | Open the music playlist |
| `[poisons` | Toggle poison application mode |
| `[sheathe` | Toggle automatic weapon sheathing |
| `[skill` | Open skill descriptions reference |
| `[skilllist` | Open skill watch list |
| `[Organize` | Sort container contents into labeled bags |
| `[ReleaseSummons` | Release all summoned creatures |
| `[regbar` | Show reagent counts |

## Quest Commands

| Command | What It Does |
|---|---|
| `[quests` | Open your quest log |

## Spell Bar Commands

Each magic school has its own spell bars. Examples:

| School | Open | Setup | Close |
|---|---|---|---|
| Magery | `[mage_tool1` | `[mage_spell1` | `[mage_close1` |
| Necromancy | `[necro_tool1` | `[necro_spell1` | `[necro_close1` |
| Elementalism | `[element_tool1` | `[element_spell1` | `[element_close1` |
| Bard | `[bard_tool1` | `[bard_spell1` | `[bard_close1` |

See the [Spell Bars](../magic/spell-bars.md) page for the complete list.

## Other Useful Commands

| Command | What It Does |
|---|---|
| `[Rename <name>` | Rename a container |
| `[SkillName <skill>` | Set your character's displayed title |
| `[spellhue <number>` | Change magery spell effect color |
| `[barbaric` | Toggle barbaric play style |
| `[oriental` | Toggle oriental play style |
| `[evil` | Toggle evil play style |
| `[private` | Toggle town crier privacy |
| `[OrderBy-Name` | Sort container by name |
| `[OrderBy-Weight` | Sort container by weight |
| `[magicgate` | Find nearest moongate |
| `[corpseclear` | Delete empty corpses |

## Tips

- **Memorize the essentials** — bandself, combatbar, quickbar, loot, corpse, and magicgate are used by every player.
- **Organize your backpack** — use `[Organize` to sort items into labeled bags.
- **Track your skills** — `[skilllist` lets you watch specific skill progress.
- **Emotes are fun** — try `[emote bow` or `[emote clap` to interact with other players.
